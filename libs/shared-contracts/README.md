# Contratos publicos compartidos

Espacio reservado para contratos publicos de la API, una vez que se defina
su generacion y consumo con OpenAPI. Por ahora no contiene tipos ni un
paquete compilable.

Debe contener unicamente contratos de comunicacion seguros para clientes.
No exponer modelos Prisma completos, hashes de contrasenas, tokens de sesion
ni detalles internos del servidor. La validacion de solicitudes seguira
siendo responsabilidad del backend.
